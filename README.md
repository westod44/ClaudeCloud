# Lantern Isles

An isometric exploration game prototype that runs in the browser. Open `index.html` in a browser to play.

- All art is generated in code when the page loads. Each terrain tile is a 512×512 pixel-art block, made with limited palettes and ordered dithering.
- The island is generated with ruins, forests, cliffs and water. Unexplored areas stay hidden until you get close.
- Goal: find the 8 lost relic crystals.

**Controls:** WASD or arrow keys, or tap/click a tile to walk there. Scroll, pinch or use the +/− buttons to zoom.
